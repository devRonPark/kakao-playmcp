# 사용 패턴 가이드

Claude Desktop에 연결된 후, 자연어로 요청하면 됩니다. Claude가 상황에 맞는 tool을 자동으로 선택합니다.

---

## 패턴 1: 카카오톡 문장 번역

카카오톡에 보낼 한국어 문장을 일본어로 바꿀 때 사용합니다.

**예시 대화:**

```
나: "나 오늘 좀 늦을 것 같아, 미안" 친구한테 보낼 일본어로 번역해줘.

Claude: ごめん、今日ちょっと遅れそう。
        (Gomen, kyou chotto okuresou.)
        미안, 오늘 좀 늦을 것 같아.

        핵심 표현:
        - ごめん = Gomen = 미안 (친구 사이 편한 표현)
        - 遅れそう = okuresou = 늦을 것 같아
```

**말투별 요청 방법:**

| 상황 | 요청 예시 |
|------|----------|
| 친구 | "친구한테 보낼 말이야, 편하게" |
| 직장 동료 | "직장동료한테 정중하게" |
| 처음 만나는 사람 | "낯선 사람한테 공손하게" |
| 귀엽게 | "귀엽고 발랄하게 표현해줘" |

## 패턴 2: 내 일본어 문장 교정

직접 쓴 일본어가 자연스러운지 확인할 때 사용합니다.

**예시 대화:**

```
나: "Watashi wa gakkou ni ikimasu desu" 맞아?

Claude: 私は学校に行きます。
        (Watashi wa gakkou ni ikimasu.)
        나는 학교에 갑니다.

        교정 요약: "ikimasu" 뒤에 "desu"를 붙이면 어색해요.
        설명: 행동을 나타내는 말(ikimasu)은 이미 "~합니다"라는 뜻이라서,
              "desu"를 또 붙이면 "갑니다 입니다"처럼 이상하게 들려요.
```

**활용 팁:**
- 로마자로 입력해도 됩니다 (히라가나/한자 몰라도 OK)
- 의도한 의미를 함께 알려주면 더 정확하게 교정됩니다

```
나: "Kinou tomodachi to eiga wo mimashita" — 어제 친구랑 영화 봤다는 말이야.
```

## 패턴 3: 표현 공부

특정 일본어 표현이 궁금할 때 사용합니다.

**예시 대화:**

```
나: "よろしくお願いします"가 정확히 무슨 뜻이야?

Claude: よろしくお願いします (よろしくおねがいします)
        Yoroshiku onegaishimasu
        잘 부탁합니다 / 앞으로 잘 지내주세요

        "여기서부터 잘 부탁한다"는 마음을 담은 일본식 인사예요.
        처음 만날 때나 도움을 요청할 때 두루 씁니다.

        예문: 初めまして。よろしくお願いします。
              (Hajimemashite. Yoroshiku onegaishimasu.)
              처음 뵙겠습니다. 잘 부탁합니다.
```

## 패턴 4: 복습 카드 저장 → 퀴즈 (추천 학습 루틴)

배운 표현을 저장하고 나중에 퀴즈로 복습하는 흐름입니다.

**Step 1 — 표현 공부:**
```
나: "すみません"이 뭐야?

Claude: すみません = 실례합니다 / 죄송합니다 / 저기요
        (Sumimasen)
        ...
```

**Step 2 — 카드 저장:**
```
나: 이거 복습 카드로 저장해줘.

Claude: 저장 완료!
        카드 ID: abc-123
        すみません (Sumimasen) — 실례합니다
```

**Step 3 — 퀴즈:**
```
나: 오늘 저장한 거 퀴즈 내줘.

Claude: 오늘의 퀴즈 (3문제)

        Q1. "すみません (Sumimasen)"의 뜻은?
        힌트: 읽기: すみません
        정답: [정답 숨김 — 맞춰보세요!]

나: 실례합니다!

Claude: 정답! 정답 확인하려면 "정답 보여줘"라고 해보세요.

나: 정답 다 보여줘.
→ Claude가 reveal_answers: true로 퀴즈 재생성
```

**퀴즈 유형 선택:**
```
나: 발음 위주로 퀴즈 내줘.        → focus: pronunciation
나: 한국어→일본어 문제로 내줘.    → focus: expression
나: 뜻 맞추기로 5문제 내줘.       → quiz_count: 5, focus: meaning
```

## 학습 루틴 추천

**매일 5분 루틴:**

1. 그날 카카오톡에서 쓸 것 같은 문장 1~2개 번역
2. 새로 배운 표현 카드 저장
3. 저장된 카드로 3문제 퀴즈

```
나: 오늘 일본어 학습 시작! 먼저 "밥 먹었어?" 친구한테 보낼 표현 알려줘.
```
