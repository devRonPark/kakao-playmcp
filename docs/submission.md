# 공모전 제출용 소개 문구

## 짧은 소개 (200자 이내)

하루톡 일본어 코치 MCP는 카카오톡에서 실제로 보내고 싶은 한국어 문장을 자연스러운 일본어로 바꿔주고, 초급자도 따라 읽을 수 있도록 로마자 발음과 쉬운 설명을 함께 제공하는 개인 일본어 학습 코치입니다. 단순 번역을 넘어, 상황별 말투 변환, 핵심 표현 설명, 복습 카드, 1분 퀴즈까지 연결해 매일 부담 없이 일본어를 익힐 수 있게 도와줍니다.

## 한 줄 소개

"일본인 친구한테 이 말 자연스럽게 어떻게 보내?" — 이 질문 하나로 일본어 학습을 시작하는 MCP 코치

## 제공 Tool 목록

| Tool | 설명 |
|------|------|
| `translate_kakao_message` | 한국어 카카오톡 문장 → 자연스러운 일본어 + 로마자 + 핵심 표현 |
| `correct_japanese_sentence` | 사용자가 쓴 일본어 문장 교정 + 초급자 설명 |
| `explain_expression` | 일본어 표현 의미·발음·예문 설명 |
| `create_review_card` | 배운 표현을 복습 카드로 저장 |
| `generate_daily_quiz` | 저장된 카드로 1분 복습 퀴즈 생성 |
